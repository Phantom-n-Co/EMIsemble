# EMIsemble

Adds EMI categories for mods that only have JEI support.

Many mods only have JEI support, so their recipes are missing from EMI unless JEI is installed next to it.
EMIsemble adds native EMI categories for those mods.

## Supported mods (36)

Animal Pen, Animus: NeoVitae, Apotheosis, Apothic Enchanting, Apothic Spawners,
Applied Thaumaturge, Ars Additions, Ars Elemental, Chipped, Cognition, Construction Wand,
Cooking for Blockheads, Dungeon's Delight, Embers Re-Ignited, Enchanted, Enigmatic Legacy+,
Functional Storage, Gateways to Eternity, Golem Overhaul, Hexerei, Horseman,
Hostile Neural Networks, Immersive Engineering, Immersive Petroleum, L_Ender's Cataclysm, Malum,
Myths & Legends, Nutritional, Pagan's Blessing, Rechiseled, Risus, Super Factory Manager,
Starbunclemania, Thaumaturge, Toxony, Vanilla Backport

## Before you install

- **TMRV**: turn these mods off in its config, or their recipes appear twice.
- **Extra Apoth Compat**: don't install it alongside. Same Apotheosis pages, so the game refuses the pair
  and explains why.
- **Just Enough Spirits**: skip it. Its only page is Malum's spirit drops, which this mod already adds.

## Config

`disabledMods` in `config/emisemble-common.toml` turns individual mods off.
